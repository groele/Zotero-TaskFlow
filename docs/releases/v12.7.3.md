# Zotero TaskFlow 12.7.3

Date: 2026-10-30. Stable release.

## Changes

- Let long item-pane task titles grow to their full height instead of overflowing native Zotero button sizing into controls and reading steps.
- Move the Zotero locate action below the title so narrow sidebars keep title and checklist content readable.
- Make the generate-reading-checklist action fill its own row with a larger click target.
