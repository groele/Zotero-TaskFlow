# Zotero TaskFlow 13.1.0 发布说明

## 内部通信协议升级与纯净化解耦完善

本版本为 **Zotero TaskFlow** 的功能与架构完善版本（v13.1.0），在 v13.0 全面推行纯净 TaskFlow 体系的基础上，进一步将内部底层通信协议、方法命名、图标资产与文本细节彻底规范化：

1. **底层通信协议升级至 `TASKFLOW_*`**:
   - 前端工作区桥梁（`zoteroBridge.js`）与宿主监听（`index.js`）全面升级为现代标准的 `TASKFLOW_*` 消息协议（如 `TASKFLOW_READY`, `TASKFLOW_STORAGE_SET`, `TASKFLOW_LOCATE_ITEM`, `TASKFLOW_OPEN_PDF`, `TASKFLOW_SYNC_NOTE` 等），实现全链路语义纯净化。
   - 消息层采用智能前缀路由，保持对外部调用与测试用例的双向平滑兼容。

2. **核心方法与挂载命名规范**:
   - 宿主操作方法规范为 `openTaskFlow` 与 `triggerTaskFlowOpen`，消除了代码内部残留的历史命名。
   - 前端离线/独立预览缓存前缀规范为 `taskflow_`。

3. **视觉图标与文本彻底对齐**:
   - 工具栏按钮、侧边栏导航条及内部选项卡图标全面切换为官方矢量图标 `icons/taskflow.svg`。
   - 彻底修复导入弹窗、研读概览摘要与打印视图 HTML 标题中残留的历史文案。
   - 严格限定 Zotero 兼容版本上限为 `12.*`。
