# Zotero TaskFlow v14.1.1 发布说明

发布日期：2026-10-31
适用架构：纯净 TaskFlow 体系架构（设置页语义无障碍与 DOM 清理健壮性强化）

## 1. 核心改进

- **设置页分组标题语义精准化**：
  - 将 **设置 → Zotero 文献联动** 中的第三分组子标题由“文献详情侧栏 (ItemPane)”优化为“文献详情侧栏与列表右键菜单”，准确概括该分组内包含的文献详情栏展示与列表右键菜单功能开关。
- **表单控件无障碍可访问性（Accessibility / ARIA）强化**：
  - 为自定义学术研读标签输入框补充 `aria-label="新学术研读标签名称"`。
  - 为数据导入与灾备恢复模式选择框补充 `aria-label="数据导入合并模式"`，全面满足辅助技术与键盘读屏支持。
- **DOM 监听器注销与生命周期健全性**：
  - 在文献列表菜单的动态显隐监听机制中，注册 `itemMenu.addEventListener('popupshowing', ...)` 的同时将其纳入 `windowElements` 生命周期跟踪。
  - 在窗口卸载或扩展注销时确保解绑 `popupshowing` 监听器，杜绝潜在的内存泄漏或孤立闭包引用。
- **版本与文档同步演进**：
  - 同步更新中英文项目说明 `README.md` 与 `README.en.md`。
  - 设置面板 `preferences.xhtml` 保持最新版本徽标与构建说明同步。
