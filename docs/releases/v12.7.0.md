# Zotero TaskFlow 12.7.0

Add an unfinished-task count to the existing colored toolbar icon. Count parent tasks globally, including in-progress tasks; do not count subtasks separately. Hide the badge at zero, cap visible text at 99+, and expose full unfinished/overdue counts in localized tooltips and accessible labels. Hover refreshes the date-based overdue count; committed data changes refresh all main-window badges. No polling is introduced.

The existing colored icon files and icon dimensions are retained. Pending startup reads ignore removed windows/buttons; badge styling is removed on window cleanup.
