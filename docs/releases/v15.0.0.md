# Zotero TaskFlow v15.0.0 发布说明

发布日期：2026-11-05
适用架构：现代 esbuild + TypeScript 模块化编译流水线架构（Zotero Flow 统一工程标准里程碑大版本）

---

## 1. 里程碑大版本升级概览

Zotero TaskFlow 正式发布 **v15.0.0** 大版本更新。本次升级是 TaskFlow 发展历程中的核心架构里程碑，彻底完成从传统散装覆盖式加载结构向现代化 **TypeScript + esbuild** 模块化工程流水线的战略性演进，全面融入 Zotero Flow 统一架构标准。

### 核心改进与技术亮点

- **TypeScript 全栈模块化重塑 (`src/`)**：
  - 源码全面采用 TypeScript (ESM) 编写，彻底告别历史上数千行单文件与散落手写 JS 脚本；
  - 核心子系统高度模块化与解耦：
    - `src/config.ts`：全局首选项默认值与插件运行时常量契约；
    - `src/taskRules.ts`：纯函数学术任务领域规则、代际并发乐观锁与定时器指纹计算引擎；
    - `src/literatureWorkflow.ts`：文献研读流水线、精读里程碑与学术日历调度规则；
    - `src/itemPane.ts`：条目详情侧边栏 Web Component 原生交互组件与安全渲染引擎；
    - `src/index.ts`：宿主单例主入口与多窗口生命周期调度中枢；
    - `src/types/zotero.d.ts`：完备的 Gecko / Zotero 10 ~ 12 宿主环境类型体系。

- **现代化高速构建与统一命令契约**：
  - 配备严格的 `tsconfig.json`（目标 `ES2022` / `ESNext`），编译期前置类型守卫；
  - 引入 `esbuild` 现代高速编译流水线，面向 **Firefox 140+ / Gecko 153+** 标准输出单一高性能自包含宿主 IIFE 主包 `chrome/content/scripts/index.js`（188KB）；
  - 全系标准对齐统一 NPM 脚本：
    - `npm run tsc`：执行全量静态类型检查；
    - `npm run build:source`：执行 esbuild 模块编译打包；
    - `npm run build`：一键自动执行类型检查、源码编译、哈希更新与 XPI 归档校验；
    - `npm test`：运行全量 158 项自动化测试套件与打包测试。

- **现代化生命周期机制与防御性安全闭环**：
  - 全面遵循现代无重启扩展契约，通过 `aomStartup.registerChrome` 动态注册 Chrome 协议；
  - `shutdown()` 生命周期穿透枚举并主动关闭所有打开的伴随独立窗口（`Todolist_SubWindow`, `Todolist_Window`）并注销投递定时器；
  - 条目详情侧栏对非可编辑（只读）文献实施防御性状态守卫，杜绝伪成功通知；
  - 宿主与前端统一实现 CSV 导出 Excel 公式注入（`=`, `+`, `@`, `-`）前缀防御。
