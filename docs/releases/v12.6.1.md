# Zotero TaskFlow 12.6.1

Released: 2026-10-22

## Fixed

- Remove the mismatched white filter panel in the sidebar by scoping main-toolbar styles to the main content.
- Align primary actions, selected navigation and ordinary selected counters with the Flow blue accent. Keep ordinary navigation neutral and overdue indicators red.
- Separate filled-control colors from accent text so white labels and completion marks remain readable in dark mode.
- Keep narrow-drawer actions and labels readable when compact desktop styles also apply.
- Declare the explicit light color scheme and preserve the existing dark, automatic and Zotero-following theme paths.

## Installation and compatibility

Install `zotero-taskflow-12.6.1.xpi` using Zotero's add-on manager, or check for updates. Existing task data, add-on IDs, preferences and update-feed aliases remain compatible. This patch does not expand the declared Zotero compatibility range.

## Verification

- All 128 automated tests passed, with zero failures or skips.
- The exact release XPI was checked in an isolated Windows Zotero 10.0.6 profile: light/dark × expanded/collapsed, plus two narrow-drawer cases. Two simulated host-theme notifications also propagated through the native UI bridge.
- Real computed-style and screenshot checks confirm a shared sidebar surface and readable primary buttons and navigation (contrast above 4.5:1). The overdue badge uses controlled UI state for palette checks; test-window animations are disabled to avoid hidden-window interpolation artifacts.
- The package's 131 runtime files match the reviewed source. Installer SHA-256 and package identity are in the attached verification report.

## Known limitations

Native acceptance for this patch covers palette and layout behavior, not a fresh full task workflow, manual main-profile installation or every declared host version. The previously reported cold-start `uncaught exception: undefined` diagnostic remains under investigation; this patch does not claim to fix it or guarantee an error-free Zotero log.
