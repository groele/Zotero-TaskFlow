# Zotero TaskFlow v15.0.1 发布说明

发布日期：2026-11-06
适用架构：现代 esbuild + TypeScript 模块化编译流水线架构（架构治理与债务清零版本）

---

## 1. 架构债务彻底清零与版本升级概览

Zotero TaskFlow 正式发布 **v15.0.1** 版本。本次升级对 TaskFlow 全系架构债务进行彻底攻坚与重构清债，全面拆解历史超大单例模块，建立严格的架构守卫测试，并彻底移除历史版本的兼容包袱，实现 100% 现代化的纯净代码底座。

### 核心改进与技术亮点

- **历史超大单例模块彻底拆解与领域解耦**：
  - `src/itemPane.ts`（原 848 行）：拆分为 DOM 视图渲染、右键菜单、拖拽交互、快速新建、研读模板与任务调度子模块（`src/itemPane/`），各子文件控制在 60~260 行以内；
  - `src/modules/windowToolbar.ts`（原 597 行）：拆分为功能按钮工具组、快捷键与菜单组、宿主消息通信桥梁组（`src/modules/toolbar/`），主控制器瘦身至 131 行；
  - `src/preferences.ts`（原 524 行）：拆解为首选项数据模型（`model.ts`）与动态 UI 绑定控制器（`uiBinding.ts`），主入口精简至 74 行；
  - `src/modules/literature.ts`（原 462 行）：拆解为文献任务映射（`literatureMapping.ts`）、阅读计划规划（`literaturePlan.ts`）与子笔记状态同步（`literatureSync.ts`），主模块精简至 71 行。

- **建立架构基线与自动化守卫测试**：
  - 建立 `scripts/architecture-baseline.json`，声明 `debtCleared: true` 与 0 超限模块；
  - 建立 `scripts/architecture-guard.mjs`，纳入 14 项自动化架构约束测试（涵盖 360 行上限、状态标签规范、Fluent 对称性与零硬编码、首选项双向绑定、Gecko 废弃 API 扫描、版本对齐与 SHA-512 校验等）；
  - 全系 30 个 TypeScript 源码文件全部控制在 302 行以内（严格遵守 $\le 360$ 行铁律）。

- **彻底终结历史版本兼容包袱**：
  - 彻底移除对历史 `[Todolist]` 笔记与标签的兼容检测与迁移代码，全面采用纯正 `[TaskFlow]` 标识与 `TaskFlow` 标签；
  - 清理设置面板启动绑定中的历史别名，直连现代控制器；
  - 移除冗余的派发拦截与历史按钮探测逻辑，保证代码库的高效与纯净。

- **XPCOM 原生现代化与生命周期健壮性**：
  - `bootstrap.js` 全面升级为现代 Gecko XPCOM 简写标识符（`Cc`/`Ci`），摒弃过时的全局对象调用。
