# Zotero TaskFlow v12.0.0

**全新标识系统与重大架构升级 (Major Identity System Upgrade)**

- **中文定位 (Positioning)**: 面向科研文献的智能任务管理与研究计划工作台。
- **官方仓库 (Repository)**: [groele/Zotero-TaskFlow](https://github.com/groele/Zotero-TaskFlow)

---

## 1. 全新标识系统 (New Identity Architecture)

本次重大版本更新（v12.0.0）将插件全面升级为 **Zotero TaskFlow**，建立全新的技术标识体系，并对旧版本提供 100% 平滑无感的数据与配置迁移支持：

1. **扩展 ID (Add-on ID)**：
   - 全新主 ID：`taskflow@groele.org`
   - 向下兼容别名：`todolist@groele.org`
   - `manifest.json` 与 `update.json` 全面对齐，老用户可通过自动更新无缝升级。

2. **Chrome 协议命名空间 (Chrome URL Scheme)**：
   - 全新主路径：`chrome://taskflow/content/`
   - 兼容映射：`chrome://todolist/content/`
   - `chrome.manifest` 与 `bootstrap.js` 同时注册双命名空间，跨域消息源检查全面适配。

3. **任务数据持久化与自动迁移 (Data Storage & Transparent Migration)**：
   - 全新数据存储文件：`taskflow-data.json`
   - 首次启动时若未发现新文件，自动从原有 `todolist-data.json` 读取全部历史任务、子任务、文献关联及自定义标签，并自动原子写入 `taskflow-data.json`，确保老用户升级零数据丢失。

4. **首选项配置树 (Preferences Branch)**：
   - 全新配置前缀：`extensions.taskflow.*`
   - 优先读取 `extensions.taskflow.*`，若未配置则无缝回退至 `extensions.todolist.*`。
   - 任何偏好更改同步写回两套配置树，保障跨版本与脚本协同的完全一致。

5. **本地化与多语言 (Localization)**：
   - 新增 `locale/zh-CN/taskflow.ftl` 与 `locale/en-US/taskflow.ftl`，提供标准的 `taskflow-*` 消息键。
   - 保留原 `todolist.ftl` 并互为别名映射，保障原生 ItemPane 标题与侧边栏图标无缝渲染。

6. **全局宿主对象 (Global Host Namespace)**：
   - 全新宿主命名空间：`Zotero.TaskFlow`
   - 兼容全局镜像：`Zotero.Todolist = Zotero.TaskFlow`
   - 偏好面板全局对象：`window.TaskFlow_Preferences` 与 `window.Todolist_Preferences`。
