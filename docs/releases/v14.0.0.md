# Zotero TaskFlow 14.0.0 发布说明

## 全面现代架构与零包袱纯净化 (Major Release)

本版本为 **Zotero TaskFlow 14.0.0** 重大里程碑主版本，彻底终结了过去所有模块中残留的历史兼容代码，实现了从宿主层、通信协议、前端页面、诊断工具、设置面板到语言包的 100% 现代纯净化：

1. **前端页面与工具链全面纯净化**:
   - `index.html`：参数探测与初始化全面接入 `_taskflowPending`。
   - `diagnostics.js`：全局挂载 `TaskFlowDiagnostics`，诊断日志上报全面采用 `TASKFLOW_DIAGNOSTIC`。
   - `chromeMock.js`：脱机/单机模拟环境的存储前缀全面切为 `taskflow_`，提供 `_taskflowMock`。
   - `utils.js` & `notifications.js`：全面对齐新架构标识。

2. **设置面板前端脚本（`preferences.js`）双向现代解析**:
   - 对所有 DOM 容器、状态提示、操作按钮与输入框引入智能定位，优先原生绑定 `taskflow-*` 命名规范，兼顾跨版本平滑适配。
   - `openPreferencesPane` 正式升级为优先打开 `taskflow-preferences-pane`。

3. **废弃历史语言包彻底移除**:
   - 彻底删除 `locale/en-US/todolist.ftl` 与 `locale/zh-CN/todolist.ftl`，仅保留官方纯净语言包 `locale/*/taskflow.ftl`。
   - 升级相关单元测试，彻底消除测试层对废弃文件的依赖。

4. **宿主环境与兼容上限**:
   - 官方插件 ID：`taskflow@groele.org`。
   - 兼容宿主范围严格限定为 Zotero 10 至 12（`strict_min_version: "10.0.0"`, `strict_max_version: "12.*"`）。
