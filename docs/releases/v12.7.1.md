# Zotero TaskFlow 12.7.1

Date: 2026-10-30. Stable release.

## Changes

- Put a clearly labeled “移除” action beside task titles in both the main task cards and Zotero item pane. It removes only the TaskFlow task, leaves the linked Zotero library item untouched, and retains the existing undo behavior.
- Restrict the toolbar badge count to non-overdue tasks whose status is to do or in progress. Completed and overdue tasks are excluded; tooltips and accessible names continue to report overdue tasks separately.
- Preserve the existing colored icon and its dimensions.

## Validation

- 150 Node tests and 5 package-policy tests passed.
- Production XPI built with the repository packaging script; release tag syntax/version self-check passed.
- Seven controlled checks passed against the actual toolbar in isolated Zotero 10.0.7, including due-date/status transitions and 99+ capping. The isolated profile and data directory are under `output/taskflow-delete-badge-20261030/`.
- Main-card and item-pane removal, undo retention, and preservation of the linked Zotero item are covered by DOM/host integration tests. The new button placement has not received a separate screenshot-based visual review in Zotero.
