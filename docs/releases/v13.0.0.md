# Zotero TaskFlow 13.0.0 发布说明

## 架构升级与纯净化解耦 (Pure TaskFlow)

本版本为 **Zotero TaskFlow** 的重大主版本升级（Major Release: v13.0.0），全面推倒并移除了所有早期 Todolist 历史向后兼容包袱与冗余回退层，实现纯净现代的 TaskFlow 架构体系：

1. **统一扩展身份**:
   - `manifest.json` 与应用身份彻底迁移为官方纯净 ID `taskflow@groele.org`。
   - `chrome.manifest` 纯净注册 `taskflow` content 与 locale 命名空间，移除所有 todolist 历史别名注册。
   - `bootstrap.js` 全面精简为纯净的 TaskFlow 启动与关闭流程。

2. **纯净首选项管理体系**:
   - 彻底废除 `extensions.todolist.*` 兼容项与双写同步，所有设置项与配置读写完全基于 `extensions.taskflow.*`。
   - 首选项配置读写与回滚机制纯净化，绝无性能损耗与配置混淆。

3. **纯净数据存储体系**:
   - 数据文件纯净采用 `taskflow-data.json`，诊断日志纯净采用 `taskflow-debug.json`。
   - 移除冗余的早期历史数据探测与自动迁移兜底分支。

4. **侧边栏 (ItemPane) UI 深度精致化**:
   - **快速添加按钮优化**: 淡化新建按钮色彩，采用 Zotero 原生设计变量与柔和中性边框，彻底杜绝文字折行与字体溢出问题。
   - **底部动作网格对齐**: 精确采用 2 列自适应网格，将“打开 PDF”紧随“同步子笔记”右侧并列排版，布局整洁规整，无缝适应各种窗口宽度。
