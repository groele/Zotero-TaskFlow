# Zotero TaskFlow 12.6.0

Released: 2026-10-22

## Added

- Make four existing preferences effective: task-card navigation, library drag-and-drop, PDF page/annotation navigation, and compact companion layout.
- Keep explicit edit and locate buttons available independently of the card-click preference.

## Fixed

- Read the actual `zotero/item` drag payload instead of the currently selected item. Import multiple reading tasks atomically, resolve attachments to parent items, distinguish libraries, and skip existing active reading tasks.
- Show failed writes and allow retry without leaving partial task batches.
- Load a single Fluent resource containing both current and legacy message IDs.
- Allow evaluation builds to select a separate output path.

## Installation and compatibility

Install `zotero-taskflow-12.6.0.xpi` through Zotero's add-on manager. Existing task data and preferences remain compatible. Unsupported settings remain visibly disabled. The existing declared Zotero range is unchanged; this release's native verification covers Zotero 10.0.6 only.

## Verification

- All 128 automated tests passed, with zero failures or skips.
- Focused isolated Zotero 10.0.6 acceptance covers the real UI/bridge/storage chain, settings and localization. Drag events are synthesized in the native document; PDF navigation is checked at the host-call boundary.
- Exact release package identity and checksums are included in the attached verification report.

## Known limitation

Isolated cold startup can log an `uncaught exception: undefined` diagnostic without a source or stack. Focused functionality passes, but the startup diagnostic remains under investigation; this release does not claim an error-free host log.
