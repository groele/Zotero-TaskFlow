# Zotero TaskFlow 16.0.0

Zotero TaskFlow 正式发布 **16.0.0** 大版本，标志着全系统一大版本（Zotero Flow Unified Major Release 16.0.0）协同确立。

## 🌟 核心升级与特性

1. **统一全系大版本号**：跃升至 16.0.0，与 Zotero Flow 家族其余六大插件保持完全一致的版本号与契约；
2. **纯净现代化架构底座**：彻底拆除历史超大单例模块，建立涵盖 30 个 TypeScript 模块的纯净架构（全部 <= 360 行，0 债务）；
3. **架构守卫与自动化套件**：建立严格的 architecture-guard 自动化守护套件，类型检查与静态测试 100% 通过；
4. **双向 Fluent 本地化中英双语严格对称**：设置面板 100% Fluent `data-l10n-id` 驱动，零硬编码；
5. **完整自动化测试验证**：186 项单元测试与集成测试全量通过。
