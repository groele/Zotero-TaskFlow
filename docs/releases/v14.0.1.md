# Zotero TaskFlow v14.0.1 发布说明

发布日期：2026-10-30
适用架构：纯净 TaskFlow 体系架构（去除历史版本与弃用资产）

## 1. 核心改进

- **彻底清除历史旧版本构建包与二进制遗留**：从 Git 跟踪树中彻底移除了早期历史构建包 `todolist-zotero-1.0.0.xpi`，使代码库避免打包大二进制遗留。
- **清理已废弃的历史版本设计素材与转换脚本**：
  - 移除了早期版本演进中用到的风格切换与图标导出工具：`scripts/apply_icon.py`、`scripts/update_to_v11_icons.py`、`scripts/export_all_icons.py`。
  - 移除了已废弃的候选设计草稿目录 `icons/` 及其下的 85 个历史图片与 SVG 文件（缩减逾 1MB 冗余素材）。
  - 运行时与打包体系完全统一使用根目录品牌图标（`icon.png`, `icon@2x.png`）及 `chrome/content/icons/taskflow.svg`。
- **净化 `update.json` 自动更新源**：
  - 彻底移除了已退役的 `todolist@groele.org` 历史升级列表（缩减近 300 行冗余条目）。
  - 仅保留权威规范的 `taskflow@groele.org` 更新源，并配置 v14.0.1 的精确发布资产与 SHA-256 校验和。

## 2. 验证结果

- **包构建**：`python scripts/build-package.py` 构建通过，产物 `zotero-taskflow-14.0.1.xpi`（482,336 字节，129 文件），SHA-256 匹配。
- **单元测试**：`npm test` 包含 152 项单元测试与打包测试 100% 通过。
