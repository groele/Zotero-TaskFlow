# Zotero TaskFlow v14.2.3 发布说明

发布日期：2026-11-04
适用架构：纯净 TaskFlow 体系架构（模块化设置面板重构与全链路稳健性防护）

## 1. 核心改进

- **重构设置面板架构为六大业务流转模块**：
  - 严格依据科研工作心智模型自上而下顺畅流转，层级克制清晰：
    1. **工作区与主视图形态**：配置默认打开模式（选项卡/伴读子窗口/独立大窗口）、伴读置顶与紧凑流式布局、主视图与主题；
    2. **学术模板与任务默认值**：配置学术研读子任务模板预设、默认待办类型、精读清单体系与新建任务截止天数/优先级；
    3. **Zotero 文献与阅读联动**：整合详情侧栏 (ItemPane)、条目定位、拖拽建任务、右键单篇/批量加入菜单以及 PDF 选区快捷伴读；
    4. **文献子笔记云同步与自动标签**：管理文献子笔记全端云同步、待研读与精读已完成双向自动打标；
    5. **任务提醒与学术晨报**：配置每日晨报提醒时间与到期调度；
    6. **标签资产、备份与数据安全**：自定义学术标签管理、多格式全量导出/导入、快捷键速查与重置区。
- **修复独立伴随窗口生命周期关闭缺陷 [P1]**：
  - 在 `shutdown()` 生命周期注销流程中，枚举清理所有打开的 `Todolist_SubWindow` 与 `Todolist_Window`，彻底杜绝插件卸载/禁用后残留孤立窗口。
- **修复设置页底部版本卡片与操作按钮样式失效缺陷 [P1]**：
  - 增强 `preferences.css`，双向兼容 `.todolist-pref-release-info` 与 `.todolist-release-info`、`.todolist-action-group` 与 `.todolist-pref-actions`，使底部版本信息卡片与导出/操作按钮网格样式 100% 精准命中。
- **修复只读条目子笔记同步与假阳性提示 [P2]**：
  - 条目详情侧边栏在检测到文献条目处于只读群组或不可编辑状态（`!target.isEditable()`）时自动将「同步子笔记」按钮置灰禁用并给出明确提示；
  - 严格校验 `syncTasksToChildNote` 返回值，条目未成功同步时绝不弹出虚假“同步成功”通知。
- **修复按钮重复监听与 CSV 导出公式注入风险 [P2]**：
  - 移除 `ui.js` 中对 `#btn-zotero-prefs` 冗余重复绑定的第二次 click 监听器；
  - 宿主 `exportData('csv')` 增加 Excel 宏与公式注入防护，对开头为 `=, +, @, -` 的单元格内容强制添加 `'` 单引号安全转义。
