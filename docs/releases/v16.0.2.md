# Zotero TaskFlow 16.0.2

Zotero TaskFlow 发布 **16.0.2** 质量修复版本，重点解决看板拖拽状态同步、ItemPane 拖放、计时器退出结算、跨窗口并发更新与设置联动等核心可靠性问题。

## 修复与改进

1. **看板显式状态与逾期列一致性**：通过 `statusExplicit` 标记统一 `moveTaskToKanbanColumn` 与 `getKanbanStatus` 的判定规则，拖拽逾期任务至待办/进行中或拖拽普通任务至逾期列均可稳定持久化且保留原截止日期。
2. **ItemPane 文献拖放与卡片排序**：完善 `setupPaneDragAndDrop` 与 `makeTaskCardDraggable`，支持从文献库拖入 `zotero/item` 条目创建研读待办，以及通过 `text/x-taskflow-id` 拖拽调整卡片排序并保存 `order`。
3. **计时器退出结算**：在 `app.js` `unload` 与 `TaskFlowHost.shutdown` 中通过 `stop_all` 原子结算运行中的 `activeTimers` 到 `timeEntries`，避免关闭窗口后的离线挂钟时间污染任务耗时。
4. **看板断链警示对齐**：`createKanbanTask` 与列表卡片对齐，展示 `zoteroLinkStatus` (`missing` / `trashed`) 文献状态警示徽标。
5. **跨窗口并发刷新不丢失**：`UI.init` 与 `TaskManager` 在 `_mutating` 期间缓存 `Storage.subscribe` / `chrome.storage.onChanged` 到达的更新并于操作结束时应用。
6. **设置联动、提示音与本地化完善**：在提醒分组恢复 `enableSound` 开关，新增 `src/preferences/dependencies.ts` 实现 `updateDependencies()` 全生命周期联动与 `Zotero.Prefs` 监听同步，并为动态下拉选项、状态栏及 ItemPane 操作按钮补充对称 Fluent `data-l10n-id`。
7. **本地日历日期修复**：`DataManager.getStatistics` 平均提前天数与 `TaskFlowStorage.exportData` 导出文件名统一采用本地日历日期，消除跨时区 UTC 偏差。
