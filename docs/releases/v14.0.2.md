- **彻底清除旧版本图标素材目录**：
  - 移除了历史遗留在仓库根目录的 `Zotero-TaskFlow-Icons-v11.2.4/` 整个目录（包含 36 个历史风格设计文件及测试页面，缩减 123 KB 冗余素材）。

- **清理根目录历史冗余文件**：
  - 移除了包含乱码的历史重定向残留文件 `README_en.md`，规范英文自述使用标准的 `README.en.md`。
