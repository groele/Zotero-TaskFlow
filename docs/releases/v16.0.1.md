# Zotero TaskFlow 16.0.1

Zotero TaskFlow 正式发布 **16.0.1** 维护版本，重点优化学术任务模态框空间与输入框尺寸，并彻底完成前端业务脚本的模块化拆解。

## 🌟 核心升级与改进

1. **模态框空间与可编辑文本框重塑**：
   - 模态框整体扩展至 720px 宽度与最高 780px 呼吸感高度，圆角统一提升至 12px 搭配现代弥散投影；
   - 任务标题框高度由 31px 提升至 38px，强化聚焦光环；
   - 任务描述文本框彻底解除低矮限制，默认 min-height 提升至 84px，行高 1.55，开放垂直自由拖拽与动态输入高度伸缩；
   - 学术类型切换胶囊、优先级、分类下拉框及主辅操作按钮尺寸与排版全面对齐黄金视觉规范。
2. **前端巨型脚本彻底拆解（$\le 360$ 行硬防线）**：
   - 将原 `modal.js` (879 行) 拆分为 `modalSubtasks.js`、`modalLiterature.js`、`modalForm.js` 与 `modal.js`；
   - 将原 `taskManager.js` (730 行) 拆分为 `taskQueries.js`、`taskBatch.js`、`taskOperations.js` 与 `taskManager.js`；
   - 将原 `ui.js` (1557 行) 拆分为 `uiState.js`、`uiActions.js`、`uiViews.js`、`uiDelegation.js`、`uiInlineEdit.js`、`uiEvents.js` 与 `ui.js`；
   - 将 `zoteroBridge.js` 深度精简至 303 行（自包含）；
   - 全仓库所有可编辑源码文件单文件严格遵守 $\le 360$ 行红线（最高 321 行），债务彻底清零。
3. **架构守卫与沙箱兼容性加固**：
   - 消除 `redesign.css` 遗留的微小悬挂样式声明；
   - 强化所有解耦子模块在非浏览器环境与跨沙箱执行时的全局绑定保护；
   - 158 项核心自动化集成测试、15 项架构守卫规则及 6 项打包测试 100% 通过。
