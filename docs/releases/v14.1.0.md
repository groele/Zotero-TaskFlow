# Zotero TaskFlow v14.1.0 发布说明

发布日期：2026-10-31
适用架构：纯净 TaskFlow 体系架构（文献右键菜单独立偏好开关）

## 1. 核心改进

- **新增文献列表右键菜单功能开关**：
  - 在 **设置 → Zotero 文献联动** 中新增了针对文献列表右键菜单的独立功能开关：
    - `extensions.taskflow.itemContextMenuCreate`：控制是否在文献右键菜单中显示“添加为待办”。
    - `extensions.taskflow.itemContextMenuBatch`：控制是否在文献右键菜单中显示“批量加入研读待办”。
  - **默认状态均为未开启**：保持 Zotero 文献右键菜单整洁清爽，按需在设置中启用。
- **现代化动态菜单控制架构**：
  - 在 Zotero 7/8 原生 `MenuManager` 下通过 `onShowing` 动态读取偏好并控制 `setVisible`，设置修改后即时生效。
  - 在非 MenuManager 环境与回退 DOM 注入模式下，监听 `popupshowing` 动态切换菜单项与分隔线的 `hidden` 状态，彻底避免空分隔线与冗余菜单项常驻。
- **配置与自述文档同步更新**：
  - 同步更新中英文项目说明 `README.md` 与 `README.en.md`。
  - 设置面板 `preferences.xhtml` 与 `preferences.js` 对应增加控件绑定与重置支持。
