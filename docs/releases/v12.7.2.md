# Zotero TaskFlow 12.7.2

Date: 2026-10-30. Stable release.

## Changes

- Repair the window-mode menu: construct its three labeled choices and SVG icons with native DOM APIs so Gecko retains and displays them.
- Recover the Zotero host instance for standalone TaskFlow windows and dispatch host operations directly. This fixes the stalled initialization that left window controls unbound.
- Keep message-based host communication for embedded TaskFlow tabs and frames.

## Validation

- 152 Node tests and 5 package-policy tests passed.
- The real Zotero 10.0.7 isolated-profile acceptance passed all 4 checks: host context recovery, visible three-mode menu, opening the desktop window, and returning to a TaskFlow tab.
- The release XPI passed ZIP integrity and manifest identity/version checks. The isolated profile and data directory are separate from the user's main Zotero profile.
- No user main-profile installation was performed.
