# Third-party rights and provenance

Zotero TaskFlow currently declares [MIT](LICENSE). Its README does not identify a specific source plugin from which TaskFlow was forked; absence of that declaration is **not** proof that all resources are original.

## Development dependencies in package.json (reviewed 2026-11-14)
@types/node, esbuild, jsdom and TypeScript are declared as development tools. Determine the exact resolved license and whether any component is distributed with the XPI.

## Release obligations
- [ ] Inspect all source and Git history for copied or adapted third-party code and record its exact origin.
- [ ] Inventory task templates, icons, illustrations, fonts, translated text, CSS/JS libraries and exports.
- [ ] Check all delivered XPI files for embedded code or assets and retain copyright/license notices.
- [ ] Identify runtime and build-only dependencies separately.
- [ ] Do not label copied GPL/AGPL components as MIT without a compatible rights basis.
- [ ] Record changes and license decisions before each release.

This document logs review requirements, not an affirmative infringement finding or complete clearance. Last review: 2026-11-14.
